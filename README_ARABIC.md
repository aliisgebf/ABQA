## 🛠️ التقنيات المعمارية
1. **الواجهة الأمامية (Frontend):** React + TypeScript مع Vite و Tailwind CSS (v4) و Lucide Icons.
2. **الخادم الموثوق (Backend Server):** Node.js + Express (`server.ts`) لتنفيذ العمليات الموثوقة والتحقق من الأسعار والمخزون وحماية لوحة الإدارة.
3. **قاعدة البيانات (Database):** Supabase PostgreSQL مجهزة بمخطط جداول كامل وسياسات أمان Row Level Security (RLS) ومفهرسة للبحث السريع.
4. **سلة التسوق الذكية:** حفظ محلي (LocalStorage) مع تحقق إلزامي ومباشر من الخادم (`/api/cart/verify`) قبل إنشاء رابط الواتساب لكشف أي تعديل أو فارق سعري.

## 📋 ما تم تنفيذه واختباره بنجاح (Verified Features)
- [x] **بنية الدور المستقلة (Multi-Brand Architecture):** عرض علامات تجارية مستقلة (عبدالصمد القرشي، الماجد للعود، الرصاصي، عطور الجزيرة، سويس أربيان) بهويتها وشعاراتها وبلد المنشأ.
- [x] **كتالوج المنتجات والمتغيرات:** دعم أصناف العطور، البخور، دهن العود، والمسك مع خيارات الحجم والتولة (مثل: ربع تولة، نصف تولة، تولة كاملة، 50مل، 100مل).
- [x] **الهرم العطري الكامل:** عرض نوتات القمة العطرية (Top)، قلب العطر (Heart)، وقاعدة العطر (Base).
- [x] **البحث والفلترة المتقدمة:** بحث فوري بالاسم، الماركة، أو رمز SKU، فلترة حسب الدار والتصنيف، وترتيب حسب الأحدث، السعر، أو المميز.
- [x] **التحقق الأمني من الأسعار (Trusted Cart Verification):** الخادم يعيد احتساب الأسعار الحية ولا يعتمد على أرقام المتصفح. وفي حال حدوث أي تغيير سعري يظهر تنبيه فوري للعميل قبل الطلب.
- [x] **توليد رسالة واتساب مشفرة URL-Encoded:** رسالة منسقة تشتمل على اسم المتجر، أسماء العطور، الدور المصنعة، الأحجام، رمز SKU، السعر الإفرادي، والإجمالي بالريال السعودي.
- [x] **عدم تخزين الطلبات (Privacy by Design):** لا توجد جداول طلبات أو سجلات محادثات مخزنة، مما يوفر حماية مطلقة لبيانات العملاء.
- [x] **لوحة تحكم الإدارة المحمية:** دخول محمي للمشرفين بدون تسجيل عام، مع إحصائيات حقيقية لعدد المنتجات والدور (دون اختلاق أرقام مبيعات زائفة)، وإمكانية إدارة الأصناف والتصنيفات وإعدادات الواتساب.
- [x] **ملف التهيئة البيئية وقاعدة البيانات:** إنشاء مخطط `supabase/schema.sql` كامل وجاهز للتنفيذ.

## 🗄️ خطوات تشغيل مخطط قاعدة البيانات في Supabase
1. توجه إلى حسابك في [Supabase](https://supabase.com) وافتح المشروع `ilwwfxgcorppbqfltojo`.
2. ادخل على **SQL Editor** في القائمة الجانبية.
3. انسخ محتوى الملف `supabase/schema.sql` والصقه كاملاً، ثم اضغط **Run**.
4. سيتم إنشاء الجداول التالية مع سياسات RLS وفهارس البحث:
   - `public.store_settings`
   - `public.brands`
   - `public.categories`
   - `public.products`
   - `public.product_variants`
   - `public.product_categories`
   - `public.admin_users`
   - `public.site_pages`
